# 🩸 Blood Donation Certificate System — Chatra Somaj

A complete Flask web app that lets blood donors download a PDF certificate by entering their mobile number.

## 🚀 Full Deployment Guide

### STEP 1 — Google Sheet

1. Go to [sheets.google.com](https://sheets.google.com) and create a new sheet.
2. Name it **exactly**: `Blood Donor Database`
3. In Row 1 (header), put these columns in order:

   ```
   Timestamp | Name | Mobile | Blood Group | Donation Date | Donation ID | Units | Age | Gender | Address
   ```

4. Add one test row:
   ```
   19-06-2026 | Test Donor | 9999999999 | O+ | 19-06-2026 | TEST001 | 1 | 25 | Male | Kolkata
   ```

---

### STEP 2 — Google Cloud & Service Account

1. Go to [console.cloud.google.com](https://console.cloud.google.com)
2. Create a new project (or use existing)
3. Enable these two APIs:
   - **Google Sheets API**
   - **Google Drive API**
4. Go to **IAM & Admin → Service Accounts**
5. Click **Create Service Account** → give any name → click Create
6. Skip optional fields → Done
7. Click the service account → go to **Keys** tab
8. **Add Key → Create new key → JSON** → Download the file
9. Rename it to `credentials.json` and put it in your project folder
10. Copy the `client_email` from the JSON file
11. Open your Google Sheet → click **Share** → paste the email → set **Editor** → Share

### STEP 5 — Deploy on Render (Free)

1. Go to [render.com](https://render.com) → Sign up / Log in (use GitHub)
2. Click **New → Web Service**
3. Connect your **blood-cert** GitHub repo
4. Configure:
   - **Name**: `blood-certificate`
   - **Branch**: `main`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app`
   - **Instance Type**: Free
5. Click **Advanced → Add Environment Variable**:
   - Key: `APP_URL`
   - Value: `https://blood-certificate.onrender.com`  _(your Render URL)_
6. Click **Create Web Service**

**For `credentials.json` on Render:**

Since you can't upload a file directly, do this:

1. Open `credentials.json` → copy ALL content
2. In Render → go to your service → **Environment**
3. Add variable: Key = `GOOGLE_CREDS_JSON`, Value = paste the full JSON
4. Update `app.py` to read from this env var:

In `app.py`, replace the `get_sheet()` function with:

```python
import tempfile

def get_sheet():
    creds_json = os.environ.get("GOOGLE_CREDS_JSON")
    if creds_json:
        # Running on Render — read from env var
        import json, tempfile
        with tempfile.NamedTemporaryFile(mode='w', suffix='.json', delete=False) as f:
            f.write(creds_json)
            tmp_path = f.name
        creds = ServiceAccountCredentials.from_json_keyfile_name(tmp_path, SCOPE)
    else:
        # Running locally — read from file
        creds = ServiceAccountCredentials.from_json_keyfile_name(CREDS_FILE, SCOPE)
    client = gspread.authorize(creds)
    return client.open(SHEET_NAME).sheet1
```

### STEP 6 — Generate & Print Camp QR

After deploy, run:

```bash
python generate_qr.py https://blood-certificate.onrender.com
```

This creates `static/qr.png` — print this and put at the donation camp.

Link the form responses to your **Blood Donor Database** sheet.

Volunteers fill the form → data auto-appears in sheet → donor scans QR → gets certificate.

## 🆘 Common Issues

| Problem | Fix |
|---------|-----|
| `gspread.exceptions.SpreadsheetNotFound` | Sheet name doesn't match exactly OR forgot to share sheet with service account |
| `FileNotFoundError: credentials.json` | Put the credentials file in project root |
| PDF doesn't download | Make sure `reportlab` and `pillow` are installed |
| Render app sleeps | Free tier sleeps after 15 min. First request is slow. Upgrade to Starter ($7/mo) for always-on |
